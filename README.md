# FocusFlow - Pomodoro Timer

Webブラウザ上で動作する、シンプルでモダンなポモドーロタイマーアプリケーションです。
PWA (Progressive Web Apps) に完全対応しており、PCのデスクトップやスマートフォンのホーム画面に追加することで、ネイティブアプリのように快適に利用することができます。

---

## 主な機能

### マルチデバイス対応と3つのモード
PCでもスマートフォンでも、縦画面でも横画面でも、画面のサイズやカメラ穴（ノッチ）に合わせてレイアウトが完璧に自動調整されます。
- **Main**: 全ての機能にアクセスできる通常モード（スマホでは左右スワイプで直感的にタブを切り替え可能）。
- **Mini**: 必要最小限の情報だけを表示するコンパクトモード（PC版PWAでは標準サイズが `280x320` に拡大され、視認性が大幅に向上）。
- **Bar**: 画面下部などに配置できる極細のバーモード。
*※ MiniモードおよびBarモードは、PCでPWAとしてインストールした状態でのみ利用可能です。*

### タイマー機能と自動リセット
- **多彩なプリセット**: Focus (25分 / 50分) と Break (5分 / 15分) のワンクリック切り替え。
- **自由なカスタムタイマー**: ショートカットに加え、1分から180分の間で自由にタイマー時間を設定できる「Custom」調整UI（増減ボタンおよび数値直接入力）を新たに搭載。
- **タイマー完了時の自動リセット**: タイマーが終了すると、自動的にタイマーが初期設定時間に戻ります。リセットボタンを押す手間がなく、そのままスムーズに次の作業を開始できます。
- **タスク名の入力と長文省略**: 実行中のタスク名を入力・表示可能。タスク名が長い場合は、Main/Mini/Barのどのモードでも表示領域に合わせて末尾が自動で `...` に美しく省略され、レイアウト崩れを防ぎます。
- **Web Audio API & OS通知**: Web Audio APIを利用したクリアなビープ音と、OSネイティブの通知によるタイムアップのお知らせ。

### ダッシュボードとカレンダー
記録した作業履歴は、ただリストになるだけでなく視覚的に管理できます。
- **統計情報**: 「今日の集中時間」「直近7日間」「累計」を瞬時に計算して表示（60分を超えると自動的に h/m 表記に変換）。
- **集中カレンダー**: 日毎の合計作業時間がカレンダー上にバッジ（時間表示）として表示され、タップするとその日の詳細なタイムライン（何時から何時まで、どのタスクを行ったか、各タスクの所要時間）を確認できます。

### GitHub Gistを利用したクラウド同期
GitHubの Personal Access Token (PAT) を登録することで、Gistを簡易データベースとして利用し、複数端末間でのデータ同期が可能になります。
- **自動バックアップ**: 作業終了時に自動でクラウドへバックアップ。
- **人間が見やすい整形データ**: Gistに保存されるJSONデータは、インデント（2マスのスペース）と改行を適用した美しいフォーマットで出力され、クラウド上で直接見直す際も判読しやすくなっています。
- **手動同期**: ダッシュボードの更新（同期）・送信ボタンから、いつでも手動でローカルとクラウドのデータをコンフリクトなく統合可能。

### CSVエクスポート
蓄積された作業履歴をCSVファイルとして出力し、Excel等で分析することが可能です（Gist未連携の場合は出力後にローカルの履歴がクリアされます）。

## 技術スタック

UI構築に外部ライブラリ（TailwindCSSやコンポーネントライブラリ等）を一切使用せず、純粋なReactとVanilla CSSのみで実装することで、極めて軽量かつバグの起きにくい堅牢な設計になっています。

- React 19 (Hooks API)
- Vite 8
- Vite PWA Plugin (vite-plugin-pwa)
- HTML / Vanilla CSS

## ローカル環境での起動方法

Node.jsがインストールされている環境で、以下のコマンドを実行してください。

1. **依存パッケージのインストール**
   ```bash
   npm install
   ```

2. **開発サーバーの起動**
   ```bash
   npm run dev
   ```
   起動後、ターミナルに表示されるローカルURL（例: `http://localhost:5173/focusflow/`）にブラウザでアクセスしてください。

---

## 本番環境へのビルドと公開

GitHub Pagesなどの静的ホスティングサービスにデプロイする場合は、以下のコマンドでビルドを行います。

```bash
npm run build
```
`dist` ディレクトリに公開用のファイル一式が生成されます。

## PWAとしてのインストール方法

### 【PCの場合 (Chrome / Edge 等)】
1. ブラウザでアプリケーションを開きます。
2. 画面上部に表示される「アプリとして端末にインストールしますか？」のバナーで「はい」をクリックするか、アドレスバー右端のインストールアイコンをクリックします。
3. 専用のウィンドウで起動し、MiniモードやBarモードへの切り替えが可能になります。

### 【iPhone (iOS Safari) の場合】
1. Safariでアプリケーションを開きます。
2. 画面下部のメニューから **[共有ボタン]** をタップします。
3. **[ホーム画面に追加]** を選択します。
4. ホーム画面に作成されたアイコンから開くことで、URLバーなどが消えたフルスクリーンアプリとして快適に利用できます。

### 【Android (Chrome) の場合】
1. Chromeでアプリケーションを開きます。
2. 画面下部に表示される「ホーム画面に追加」のバナーをタップするか、メニューから「ホーム画面に追加」を選択してください。
