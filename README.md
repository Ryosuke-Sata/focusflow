# FocusFlow - Pomodoro Timer

Webブラウザ上で動作する，シンプルでモダンなポモドーロタイマーアプリケーションです．
PWA (Progressive Web Apps) に対応しており，PCのデスクトップにインストールして独立したアプリケーションとして利用することができます．

## 主な機能

- 3つの表示モード
  - Main: 全ての機能にアクセスできる通常モード．
  - Mini: 必要最小限の情報だけを表示するコンパクトモード．
  - Bar: 画面下部などに配置できるバーモード．
  ※ MiniモードおよびBarモードは，PWAとしてインストールした状態でのみ利用可能です．
- プリセットタイマー
  - Focus (25分 / 50分) と Break (5分 / 15分) のワンクリック切り替え．
- タスク記録と履歴管理
  - 作業内容と時間をブラウザのローカルストレージに自動記録．
- CSVエクスポート
  - 蓄積された作業履歴をCSVファイルとして出力可能．出力後はローカルの履歴がクリアされます．
- アラームと通知
  - Web Audio APIを利用したビープ音と，OSネイティブのデスクトップ通知によるタイムアップのお知らせ．
- ウィンドウサイズの自動調整
  - PWA起動時，各モードに合わせてウィンドウサイズを自動で最適化し，見切れなどを防ぎます．

## 本番環境へのビルドと公開

GitHub Pagesなどの静的ホスティングサービスにデプロイする場合は，以下のコマンドでビルドを行います．

```bash
npm run build

```

`dist` ディレクトリに公開用のファイル一式が生成されます．

## PWAとしてのインストール方法

1. ブラウザでアプリケーションを開きます．
2. 画面上部に表示される「アプリとしてPCにインストールしますか？」というバナーの「はい」をクリックします．
（または，ブラウザのアドレスバーにあるインストールアイコンをクリックします）
3. インストールが完了すると専用のウィンドウでアプリケーションが起動し，OSの独立したアプリとしてMiniモードやBarモードへの切り替えが可能になります．
